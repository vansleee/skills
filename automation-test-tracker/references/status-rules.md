# Tracker Status Rules

## Backlog

Use for known work that has not started.

## In Progress

Use when an agent or human has selected the task and is gathering baseline or applying a fix.

## Blocked

Use when the next step requires missing credentials, unavailable environment, unclear expected behavior, product bug confirmation, or user decision.

## Done

Use only when acceptance criteria pass and benchmark evidence is recorded.

## Cancelled

If a task no longer applies, keep the entry and mark it cancelled with a reason instead of deleting it.
